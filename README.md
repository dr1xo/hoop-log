# 🏀 HoopLog

---

## Descripción del proyecto

HoopLog es una web para llevar el registro de tu entrenamiento y tu rendimiento en la cancha:
Gimnasio: ejercicios, series, repeticiones y pesos.
Básquet: puntos, rebotes y asistencias por partido.
Progreso: historial y evolución de tus números a lo largo del tiempo.
El proyecto arranca como una página estática y evoluciona hasta convertirse en una app completa con backend en Node.js, API REST y persistencia de datos.

---

## Funcionalidades
  Registrar sesiones de gimnasio (ejercicios, pesos)
  Registrar partidos de básquet (puntos, rebotes, asistencias)
  Ver historial de sesiones y partidos
  Ver gráficos de progreso
  Guardar los datos de forma persistente
